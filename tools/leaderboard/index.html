PolOCRBench — polskie rozumienie dokumentów

Wspólny punkt odniesienia dla trudnych polskich dokumentów: A transkrypcja strony do Markdown (CER), B ekstrakcja tabel do HTML (TEDS), C ekstrakcja informacji kluczowych do JSON (field-level F1). Wynik zbiorczy to średnia (1 − CER, TEDS, F1). Ewaluacja automatyczna i deterministyczna, bez sędziów LLM; zgłoszenia w formacie AmuEval (out.tsv w kolejności in.tsv).

Ranking

Stan: pomiary kontrolne pipeline'u (4 czyste strony syntetyczne, wersja 0.1); docelowe rankingi na Test A (development) i Test B (ranking główny, ukryty do końca konkursu). Osobne tablice dla tracków: constrained (trening tylko na danych organizatora, modele open-weight), open (dowolne dane i modele), zero-shot / API (bez fine-tuningu, jednolity prompt organizatora).

Jak zgłosić wynik

  1. Przeczytaj protokół ewaluacji (formaty, normalizacja, miary) w repozytorium projektu.
  2. Uruchom publiczny skrypt ewaluacyjny lokalnie na zbiorze treningowym.
  3. Wyślij out.tsv (per podzadanie) oraz submission_meta.json z deklaracją tracku, modeli i promptu na adres wskazany przy konkursie.
